# 🛒 FreshMart – Grocery E-commerce Website

A modern and fully responsive grocery website built using **HTML5 and CSS3**.
Designed with clean UI, reusable components, and responsive grid layouts — without any frameworks.

* Category grid layout
* Responsive product cards

* Mobile-friendly layout
